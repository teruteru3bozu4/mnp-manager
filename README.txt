MNP管理 PWA（全更新版）
========================

【収録ファイル】
- index.html：CSS・JavaScriptを含むアプリ本体
- manifest.webmanifest：PWA設定
- sw.js：オフラインキャッシュ・旧キャッシュ削除
- icon.svg：アプリアイコン
- README.txt：公開・更新・データ移行の説明

【GitHub Pagesへの更新】
1. GitHubで公開先リポジトリを開きます。
2. 上記ファイルをリポジトリ内の同名ファイルとして置き換えます。
3. Commit changesで保存します。
4. 数分待って公開URLをSafariで開き、表示を確認します。
5. 古い表示が残る場合はページを再読み込みし、改善しなければホーム画面アプリを終了して再起動してください。

【iPhoneでホーム画面に追加】
Safariで公開URLを開く → 共有 →「ホーム画面に追加」。

【データ保存・移行】
契約データはlocalStorageの mnp_manager_v1、名前一覧は mnp_names_v1 に保存されます。データはこの端末・ブラウザ内にのみ保存されます。定期的にCSVでバックアップしてください。
ブラウザのデータ消去、端末変更、別ブラウザ、GitHub Pagesの公開元（オリジン）の変更などではデータが引き継がれない場合があります。旧URLでCSV出力し、新URLでCSV取込してください。旧版の mnpData キーが存在する場合は初回起動時に移行を試みます。移行前のCSVバックアップを推奨します。

【計算】
解約可能日は契約日＋保有月数の目安です。月末日は移動先月の最終日に調整します。
利益＝売却価格－購入価格－事務手数料等＋特典・CB－（月額料金×保有月数）
正式な解約可能日やキャリアの費用条件は各キャリアで確認してください。

【CSV】
UTF-8 BOM付きで出力します。履歴中の改行、カンマ、引用符に対応します。CSV取込は列名で対応し、既存IDと重複する行はスキップして追加します。旧ステータス「申込中」は「契約中」に変換します。取込は既存データへの追加であり、上書きではありません。

【注意】
重要な記録は定期的にCSV出力し、別の場所へ保管してください。
